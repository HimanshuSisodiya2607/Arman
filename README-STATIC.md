# Static HTML/CSS/JS Version

This is a converted static version of the VocalFluxStudio website, converted from React to plain HTML, CSS, and JavaScript.

## Files

- `index-static.html` - Main HTML file (static version)
- `static-styles.css` - Additional CSS styles for the static version
- `static-script.js` - Vanilla JavaScript for interactivity
- `index-BLpfRZgO.css` - Original CSS file (still used)

## How to Use

1. **Via HTTP Server** (Recommended):
   - Access via: `http://localhost/arman/clone/index-static.html`
   - Or use the Python server: `http://localhost:8000/index-static.html`

2. **Features Included**:
   - Responsive navigation with mobile menu
   - Smooth scrolling
   - Scroll-triggered animations
   - Navbar scroll effect
   - All sections from the original site

## Differences from React Version

- No React dependencies
- No build process required
- Works directly in browser
- Simpler codebase
- Some advanced animations simplified
- No routing (single page)

## Notes

- The original React version is still available in `index.html`
- Image paths may need adjustment based on your setup
- All styling is preserved from the original design
